Política de Privacidade

Esta página explica, de forma simples, quais dados este site coleta, para que servem e quais são os seus direitos. O respeito aos seus dados segue a Lei Geral de Proteção de Dados (LGPD, Lei 13.709/2018).

Quais dados são coletados

  • Dados de navegação: ao visitar o site, ferramentas de análise (Google Analytics) coletam dados como páginas visitadas, tempo de visita, tipo de dispositivo e origem do acesso, por meio de cookies. Esses dados são usados de forma agregada e não identificam você pessoalmente.
  • Dados de contato: se você fala comigo pelo WhatsApp ou por e-mail, os dados que você mesma enviar (como nome e o que descrever sobre seu filho) ficam nessa conversa, para que eu possa responder e organizar o atendimento.

Este site não tem formulário que armazene seus dados. O contato acontece pelos canais que você escolher.

Para que os dados são usados

Os dados de navegação servem para entender como o site é usado e melhorá-lo. Os dados de contato servem apenas para responder você e combinar a consulta. Nada é vendido nem usado para outros fins.

Cookies

Cookies são pequenos arquivos que o site guarda no seu navegador. Aqui eles são usados para a medição de tráfego (Google Analytics) e para lembrar a sua preferência de tema (claro ou escuro). Você pode bloquear ou apagar cookies nas configurações do seu navegador.

Com quem os dados são compartilhados

Os dados de navegação são tratados pelo Google (Google Analytics), que atua como operador. O WhatsApp, se você usar esse canal, também é um serviço de terceiro. Não há outro compartilhamento.

Seus direitos

Você pode pedir, a qualquer momento, para acessar, corrigir ou excluir os seus dados, e pode retirar o consentimento para o uso de cookies. É só escrever para diegoaalvesrosa@gmail.com.
